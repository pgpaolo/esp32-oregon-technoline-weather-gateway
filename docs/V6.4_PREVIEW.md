# V6.4.0-rc1 release candidate

This release candidate consolidates operational-management features on top of the V6.3 RF baseline. HTTPS is intentionally **not** included in this branch.

## Included

- configurable hostname persisted in NVS;
- mDNS access as `<hostname>.local` when supported by the local network/client;
- physical OLED ON/OFF fallback using a debounced short press on the configured PRG/BOOT GPIO;
- Hardware tab metadata: firmware version, Git commit, build timestamp, board and last reset reason;
- JSON configuration export/import with validation and controlled reboot;
- optional MQTT-password export; Wi-Fi credentials are never exported;
- PlatformIO pre-build injection of the short Git commit hash.
- hardware-validated SdFat microSD mount/format path with deferred CSV logging;
- top-header microSD mount/write/error badge;
- `min_spiffs.csv` application layout retaining NVS and two OTA slots.

## Physical OLED button policy

The Web OLED ON/OFF control is available on both supported boards.

The physical short-press toggle is **enabled by default only on T3-S3**. On **T3 V1.6.1** it remains disabled by default until the exact board revision/GPIO is verified.

It can be explicitly overridden in `config_private.h`:

```cpp
#define OLED_BUTTON_ENABLE 1
#define OLED_BUTTON_PIN    0
```

Do not enable the physical toggle until the selected GPIO has been verified on the exact board revision.
